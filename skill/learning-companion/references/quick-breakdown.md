# 快速拆解轻模式

用户说“快速看一下 / 速览 / 先扫一眼 / 大概讲讲 X”时用本模式。

## 原则

- 不建工作区、不落文件、不追问 Mission。
- 一次性输出，控制在能快速读完的篇幅。
- 目标是给用户一张"这东西长什么样"的地图，让他判断要不要深入，而不是教会他。
- 仍然遵守"不信任模型记忆"：涉及具体事实给一手来源，不确定就标注。

## 固定形状

按顺序输出以下三块，不加开场白和总结：

### 1. 全局地图

- 一句话说清 X 是什么、解决什么问题。
- 3-6 个组成部分 / 核心概念，每个一句话，体现它们之间的关系（主线在哪）。

### 2. 一页纸速览

从下面按对象类型挑合适的填，控制在一屏内：

- **是什么 / 为什么存在**：核心定位和它取代/改进了什么。
- **核心概念**：3-5 个绕不开的术语，每个一句话。
- **最小上手**：一个能立刻试的最小例子或入口（命令 / 代码片段 / 一个要读的文件）。
- **常见坑 / 易混点**：1-3 个新手最容易踩或搞混的地方。
- **什么时候用 / 不用**：适用与不适用场景各一两条。

### 3. 一手来源清单

- 3-5 个权威一手来源（官方文档 / 原始论文 / 标杆项目源码 / 官方规范），每个带链接或明确出处 + 一句话说明看它干嘛。
- 不放随手搜到的二手博客。

## 一页纸速览模板

```markdown
## <X> 一页纸速览

**是什么**：<一句话>

**核心概念**
- <概念 A>：<一句话>
- <概念 B>：<一句话>
- <概念 C>：<一句话>

**最小上手**
<一个命令 / 代码片段 / 入口文件>

**常见坑**
- <坑 1>
- <坑 2>

**什么时候用 / 不用**
- 用：<场景>
- 不用：<场景>

**一手来源**
- [<来源 1>](<链接>) —— <看它干嘛>
- [<来源 2>](<链接>) —— <看它干嘛>
```

## 收尾

三块输出完，用一句话提示用户：如果想认真学，可以说"我认真学一下 X"，会切换到有状态学习模式、建学习工作区、按最近发展区一步步带。
