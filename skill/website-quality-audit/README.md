# website-quality-audit

输入一个网站链接，得到面向作者的八维作品体检：哪些做得好、哪些最值得改、证据是什么，以及可交给 coding agent 的修复任务。

版本 1.0.0 · 2026-11-15。默认中文；适合个人主页、内容展示、公开 Web 工具和可授权检查的账号应用。它是一套可执行评估说明与参考规则，不是自带托管扫描器的 SaaS，也不绑定指定模型或框架。

## 使用

把整个目录复制到所用 Agent 支持的 skills 目录，按该环境文档加载；保持 references/examples 相对路径，不要求写入全局配置。不同宿主的目录与调用命令不同，本次未替用户安装或配置。

也可以在支持文件读取的 Agent 中先指定读取本目录的 SKILL.md，并要求遵循执行。

提示示例：

```text
使用 website-quality-audit 评估 https://example.com 。
这是我的个人作品集，想让访客找到相关作品和联系方法。
先做公开页面初检，输出中文八维报告和三个以内修复任务。
```

```text
使用 website-quality-audit 评估这个在线换算工具：<URL>。
检查一个有已知答案的输入、非法输入和手机操作。
没有授权写入或账号测试，请把无法验证的能力单独列出。
```

```text
按 website-quality-audit 重评附件中的历史报告，保留原采集日期。
不要把历史数值写成现在的线上实测。
```

只有 URL 即可开始；用途/任务是可选的。Agent 应先执行可独立完成的初检，确需写操作、测试数据或方向取舍时才请求补充。

## 工具与限制

推荐已有浏览器自动化工具、DevTools/Lighthouse、axe、HTTP 工具。缺少某工具时诚实降级，不能仅凭 HTML 判断交互和视觉。无需运行依赖本机绝对路径的脚本；需要新依赖时另建隔离环境。

在线工具入口、规范、阈值与边界见 [标准与工具](references/standards-and-tools.md)。默认不自动把目标提交给外部扫描网站。

输出分维度结论、覆盖范围和证据，默认无综合 0–100 分。普通 URL 初检不提供完整安全、WCAG 符合性、法律合规或真实用户满意保证。

## 示例与验证

[历史案例](examples/adong-2026-11-11.md) 使用真实旧证据重评，展示局部良好、对比度问题和大量未验证项如何共存。[验收场景](references/acceptance-cases.md) 包括 12 个合成场景及期望行为。

已做规则/链接静态校验及历史证据对照；尚未进行跨网站独立模型评测和普通作者试用，不能宣称准确率或固定修复耗时。
