# 网站质量评估规则 v1.0.0

制定/核查日期：2026-11-15。适用于 URL 初检及可选深检。详细来源见 [标准与工具](standards-and-tools.md)。

## 规则性质

- **标准要求**：具体采用 WCAG 2.2 条款等已有规范，保留适用范围及例外。本清单只选重要部分，不代表覆盖完整标准。
- **官方指标/指南**：采用 Google CWV、OWASP 等指标或指导原则，不自行扩展为统一安全/产品认证。
- **自定规则**：针对任务、内容、视觉、抽样和报告的操作性约定。公开方法，但不宣称权威机构认可。

规则 ID 稳定；一条规则可以有多个测试实例。每个实例记录状态；只有该规则所有计划适用实例已通过才能记规则通过；任一确证问题记发现问题；没有发现问题但存在未完成实例时记未验证。N/A 要有证据理由，不能用来隐藏未知。

## 画像与核心任务

每个作品记录：用途、目标用户（作者声明或推断）、公开/私有、核心任务、设备、数据/支付能力、网站版本（未知也记录）。

功能工具先找正确答案。例如温度换算输入 0°C，预期 32°F；不要用应用自己的输出反过来定义正确性。没有可靠答案时区分交互可用与结果正确性，后者未验证。

## 八维基础规则（32 条）

### C · 用途与内容清晰度

全部为自定规则，借鉴 Nielsen 可用性启发式。不得把 AI 理解代替真实用户测试。

| ID | 检查与操作 | 判断/验收规则 |
| --- | --- | --- |
| C01 | 读首屏及核心功能说明，复述“为谁解决什么问题” | 能引用可见内容支持用途解释；目标用户或功能含糊时列评估判断及具体缺失；无法确定不编造 |
| C02 | 从起始页定位核心任务入口 | 入口文案/上下文能预告动作；同名入口到不同结果、主要动作藏匿等需给具体实例；不设通用“必须三次点击”阈值 |
| C03 | 抽查说明、项目状态、示例与真实结果 | 示意/占位/归档有适当标识；承诺与可观察能力一致；事实真伪无来源则未验证，不仅凭语气断言虚假 |
| C04 | 任务结束或出错后判断下一步 | 页面解释结果及下一步；等待/收费/数据保存等影响决策的条件在相关位置说明；只对适用条件判断 |

### V · 视觉与信息层级

全部为自定规则。检查“帮助阅读与任务”的效果，风格喜好单列建议。

| ID | 检查与操作 | 判断/验收规则 |
| --- | --- | --- |
| V01 | 在两个尺寸检查主内容、标题、主要动作和次要信息 | 重要性可辨，有截图与位置依据；仅“感觉不高级”不能作为问题 |
| V02 | 抽查相同角色的按钮、标题、间距、颜色和反馈 | 相同角色视觉/行为一致，有意的上下文差异可解释；不强制某套设计系统 |
| V03 | 检查可见文本、图片、长内容、浮层和不同状态 | 无非预期重叠、截断、遮挡或信息缺失；懒加载和隐藏副本复核后才下结论 |
| V04 | 检查内容密度、文字可读性与装饰/动画 | 评价与用途关联；提供具体阅读/寻找任务测试；动画尊重减少动态偏好，WCAG 问题引用对应标准而非重复计问题 |

### F · 功能、正确性与反馈

自定任务验收规则，借鉴 Nielsen 状态可见、预防错误及错误恢复原则。

| ID | 检查与操作 | 判断/验收规则 |
| --- | --- | --- |
| F01 | 执行 1–3 个核心任务的可授权步骤 | 达到预先定义的结果；打开 URL 只证明可达；写操作未执行时不能记任务通过 |
| F02 | 用已知正确答案/预期行为验证结果 | 对业务结果有独立依据；响应 200、成功 toast、输出非空不自动成立；持久化另见 B02 |
| F03 | 对适用动作观察等待、成功、空、错误、登录过期状态 | 用户能区分状态；失败不伪报成功，有适当恢复入口；无异步操作时不强制骨架或 loading 文件 |
| F04 | 检查返回、刷新、直接访问结果页/详情页、随机 404 | 适用路由可恢复，公开不存在资源正确处理；SPA 路由与 HTTP 语义按实际架构解释；重要数据重试另见 B03 |

### M · 移动端与兼容

| ID | 性质 | 检查与验收规则 |
| --- | --- | --- |
| M01 | 自定抽样 | 在默认 1440×900、390×844 或作者指定环境完成主要步骤，无页面非预期横溢出、遮挡；记录模拟/真机及浏览器，不推广到所有设备 |
| M02 | WCAG 1.4.10 AA | 检查垂直内容在 320 CSS px 宽时的信息与功能，无需二维滚动；地图、必要二维表格等按条款例外判断，不能全页 overflow 就一律判错 |
| M03 | 自定抽样 | 菜单、浮层、软键盘（能测时）、滚动和长内容不阻断任务；客户端模拟不证明真实软键盘体验 |
| M04 | 自定抽样 | 核心功能在声明的浏览器上复核；默认单 Chrome 只能记该引擎部分抽样；根据目标用户增加 WebKit/Firefox/真机，不强迫所有项目适配所有环境 |

### P · 性能与稳定感

| ID | 性质 | 检查与验收规则 |
| --- | --- | --- |
| P01 | Google CWV | 真实用户 LCP p75 ≤2.5s；区分 URL/origin、设备和数据窗；只有实验室 LCP 时记录诊断结果并保持本规则未验证 |
| P02 | Google CWV | 真实用户 INP p75 ≤200ms；需有交互样本，TBT 或单次点击 trace 不能代替真实用户 p75；无数据记未验证 |
| P03 | Google CWV | 真实用户 CLS p75 ≤0.1；实验室无位移仅证明本次加载；三项均在适用相同数据范围良好才说对应范围 CWV 通过 |
| P04 | 官方诊断 + 自定任务 | 本地 Lighthouse 记录设备、网络、版本和单次性；可选同条件多次取中位数；另测任务等待，目标在测前按用途约定，无统一“接口必须 200ms”；实验室结果不升级为线上通过 |

### A · 可访问性

按 WCAG 2.2 选择重要样本检查，未覆盖条款始终另列，不称完整 AA 审计。

| ID | 关联条款 | 检查与验收规则 |
| --- | --- | --- |
| A01 | 2.1.1 A、2.1.2 A、2.4.7 AA、2.4.11 AA | 核心流程可键盘操作，无键盘陷阱；焦点可见且聚焦组件未被作者内容完全遮挡；抽查前几个焦点不算完整流程通过 |
| A02 | 1.4.3 AA、1.4.11 AA | 普通文字 ≥4.5:1；大字 ≥3:1（18pt 普通/14pt 粗体）；必要控件/状态/图形按非文本条款 ≥3:1；Logo、禁用/附带内容等例外按原文；背景需实际核验 |
| A03 | 1.1.1 A、1.3.1 A、2.5.3 A、3.3.1 A、3.3.2 A、4.1.2 A | 图像替代、结构、输入标签、错误提示、控件名称/角色/状态按用途检查；自动提示人工复核，卡片所有文本不一定都是可见标签 |
| A04 | 1.4.4 AA、2.5.8 AA | 文字可放大 200% 不丢内容功能（条款例外）；指针目标至少 24×24 CSS px 或满足间距、内联、等价控件等例外；不把 44px 当 AA 一刀切硬标准 |

### D · 可发现与分享

| ID | 性质 | 检查与验收规则 |
| --- | --- | --- |
| D01 | 官方指南 + 自定 | 公开代表页有与内容对应、可区分的 title 和适当描述；不保证搜索引擎采用描述；不强制标题字符数机械阈值 |
| D02 | 官方指南 + 自定 | 公开/私有索引意图一致；检查 robots、适用 sitemap、canonical/noindex 及状态；单页工具不一定需要 sitemap，私有页面不因 noindex 扣分；robots 不能代替访问控制 |
| D03 | 自定 | URL 可直接访问并能正确分享；若声称社交卡片，检查适用 OG 元信息和可访问资源；不发帖验证也不凭标签证明所有平台预览正确 |
| D04 | 自定 | 检查已发现范围的内链/导航与文档结构；Nu HTML Checker 等用于解释具体结构问题；语法警告数量不等于体验失败、SEO 满分不等于会收录/有排名 |

### S · 公开安全与隐私表现

依据 OWASP、HTTP 官方指南与实际风险，非完整安全/法律认证。

| ID | 检查与操作 | 判断/验收规则 |
| --- | --- | --- |
| S01 | HTTPS、HTTP 跳转、证书与混合内容 | 对声明域名与当前测试路径有效，重要通信不降级；仅一次 HTTPS 成功不证明证书自动续期 |
| S02 | 安全响应策略 | 记录 HSTS、CSP、frame-ancestors/XFO、nosniff、Referrer/Permissions 策略的适用性与实际值；缺失是配置观察，缺少证据不能升级可利用漏洞；CSP 需与站点兼容验证 |
| S03 | 已加载公开资源中的泄漏与敏感展示 | 对可疑字符串确认类型、上下文和秘密属性；不能把发布型 key、测试值或 source map 当确定泄漏；不输出秘密全文、不调用可疑 key 验证；未命中不等于没有秘密 |
| S04 | 可见数据收集和隐私说明 | 观察实际请求/表单与说明是否一致；无 analytics 不扣分；必要信息位置清楚；未观察不等于无追踪，也不宣称法律合规；跨境/法律问题交由适当专业审查 |

## 后端与运行专项（按能力触发，8 条）

这些是选择性工程验证规则，参考 ASVS 与 SRE，不能称完整实现对应标准。所有操作必须在授权范围和适当测试数据下进行。专项影响相关维度并单独呈现，不能被基础项抵消。

| ID | 触发条件 | 验证与证据 |
| --- | --- | --- |
| B01 | 账号、角色或用户资源 | 测未登录、角色、对象级读写授权；需要受控的 A/B 账号和资源预期；前端隐藏按钮不证明权限；缺账号保持未知 |
| B02 | 声称长期保存的数据 | 新建后刷新、重新登录/其他会话读回，按需重启测试环境；客户端 localStorage 与服务端持久化分开；toast 非证明 |
| B03 | 会产生重要副作用的请求 | 受控重复/重试/并发，不产生违背业务规则的重复结果；支付用沙箱并含状态查询/对账；不在未知生产环境连点造订单 |
| B04 | 服务端输入/上传/计算 | 验证业务规则、服务端校验、文件限制及错误数据处理；前端校验不能独自通过；独立预期答案必需 |
| B05 | 第三方依赖、异步工作 | 在受控环境模拟超时/依赖失败，验证最终状态、重试/补偿和结果查询；不能靠生产断网截图证明后端恢复 |
| B06 | 公开资源消耗、付费 API 或重要写入 | 检查授权、配额/限流配置与适用防滥用设计；负载验证另有明确授权，不自动暴力请求；缺证据未知 |
| B07 | 需要持续运作或重要数据 | 看日志/指标/告警证据与实际备份恢复、回退演练；有备份文件不等于能恢复；目标按风险设定，无通用 99.9% |
| B08 | 有仓库/部署证据或作者要求深检 | 检查支持版本、依赖、可重复部署、迁移、关键规则测试、运行成本；缺仓库不能因“源码看不到”判质量差 |

## 评估判断的操作规则

C/V 等涉及判断的规则也记录状态，但必须标“评估判断”。以指定场景中的证据与影响为准，不用“AI 觉得”作为理由。

例如 V01 问题：主按钮与背景无法区分，导致在指定任务中评估者未找到入口；提供截图和操作路径，提出调整后的寻找任务验收。若只是不喜欢配色，列风格偏好，不记录为缺陷。

真实用户测试如进行，应记录人数、是否属于目标人群、任务、协助情况、成功/耗时/卡点，不用少量样本外推总体满意度。本文没有普遍的“5 秒看懂”“3 次点击”“满意度 80 分”硬阈值。

## 优先级（自定义，不照搬扫描器 impact）

| 级别 | 定义与例子 |
| --- | --- |
| P0 阻断 | 已复现且在预期场景导致严重数据/资金/权限损害，或核心任务对目标用户不可完成且无可接受替代；需要立即处理，再讨论对应使用阶段 |
| P1 重要 | 关键任务或一类目标用户受到显著妨碍；有可用替代或影响范围较局部，仍应在扩大使用前处理 |
| P2 改进 | 可用但明显损害阅读、效率、性能或防护；可按影响和成本安排 |
| P3 建议 | 轻微一致性、收益未验证的优化、风格建议；无证据时降为待复核，不能用来吓阻上线 |

综合影响、触发概率、范围和可恢复性。axe 的 serious 标签是工具分级，不直接映射 P1/P0；未利用且未确定影响的响应头缺失也不自动映射 P1。重复根因合并为一个问题，跨维度引用同一 ID。

## 维度结论（自定义汇总）

- **优先修复**：该维度有证据支持的 P0/P1。即使其他规则未验证，问题仍需呈现，同时写清覆盖不足。
- **证据不足**：没有上述重要问题，但基线未覆盖或存在未完成的适用规则/关键实例。可附已发现 P2/P3，不能掩盖。
- **可改进**：适用计划规则均已覆盖，存在 P2/P3 问题，没有 P0/P1。
- **已检范围良好**：适用计划规则均已覆盖，未发现影响性问题。
- **不适用**：该维度所有规则均有证据证明不适用。基础八维通常不应整维轻率标 N/A。

每维列规则数 `通过/发现问题/未验证/不适用` 和场景范围，不用计数替代质量。P01–P03 无真实用户数据时性能维度可写“证据不足；本次实验室表现良好”，同时展示 lab 分数。

默认覆盖基线：所有 32 基础规则均已判状态；计划 1–3 个任务包括正常及适用异常；至少两尺寸；可访问性核心键盘流程及必要人工样本；性能区分 field/lab。未执行则诚实列未知，不为补齐表格制造无意义测试。

整体结论用自然语言限定范围。有 P0/P1 写“在进入某用途/阶段前优先处理”；重要功能未知则不能给它上线保证；不默认颁发全站“可上线/安全/符合 WCAG”认证。
